# FlipFace support and privacy

Static public support site for FlipFace, operated by Joshua Elliff.
Contact: flipfaceapp@gmail.com

This repository contains only website files and public branding assets. It does
not contain the private Flutter application, user records, credentials or backups.
No analytics, forms, external fonts, JavaScript dependencies or build step.
GitHub Pages serves the root of main.

For local preview: python3 -m http.server 8765 --bind 127.0.0.1
